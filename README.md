## 📂 TECHNICAL DEEP DIVE (L'Anatomie du Code)

Pour les développeurs et designers, voici comment la magie opère :

### 🛠 Architecture & UX
* **Glassmorphism & Gradients** : Utilisation de variables CSS (`--glass-bg`, `--accent`) pour créer une esthétique "aérienne" qui réduit la fatigue visuelle lors de la lecture.
* **Semantic Search Engine** : Filtre JavaScript temps réel pour une recherche instantanée dans le lexique, sans rechargement de page (SPA feel).
* **Typography Pairing** : *Amiri* (pour l'arabe) et *Inter* (pour le français) pour une lisibilité transculturelle optimale.
* **CSS Animations** : `slideUp` et `fadeIn` pour une expérience fluide et "premium".
